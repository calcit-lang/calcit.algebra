  method signatures.

  APIs while retaining runtime traits on constructed values.

  `Expr<Dynamic>` result of the phase-aware `in-rust:` macro.

Validated with strict Caps/toolchain checks, canonical formatting, native and
JavaScript behavior tests, static quality/deprecation analysis, and immutable
Yarn dependencies.
