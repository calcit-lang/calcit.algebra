# Upgrade Calcit to 0.13.77

## English

Prepared the repository-level toolchain migration from Calcit 0.7 to 0.13.77:

- renamed `package.cirru` to `deps.cirru` and declared Calcit 0.13.77;
- moved the archived `calcit-test` module to development dependencies;
- aligned `@calcit/procs` and Yarn 4.12.0 metadata;
- added current generated/local state ignores;
- preserved the legacy compact Snapshot while testing the documented migration chain.

The Snapshot upgrade is blocked by calcit-lang/calcit#742. Calcit 0.13.77 converts the legacy direct-quote source but emits a Dynamic schema for `algebra.test/in-rust:` and requires Calcit 0.13.51; versions 0.13.50 and 0.13.51 cannot read the original direct-quote namespace entries, while 0.13.51 cannot read the 0.13.77 output either. No target-repository PR should be opened until the core migration path is fixed and all gates pass.

Checkpoint coordination: calcit-lang/calcit#731.

## 中文

已准备从 Calcit 0.7 升级到 0.13.77 的仓库级工具链迁移：

- 将 `package.cirru` 迁移为 `deps.cirru` 并声明 Calcit 0.13.77；
- 将已归档的 `calcit-test` 模块归入开发依赖；
- 对齐 `@calcit/procs` 与 Yarn 4.12.0 元数据；
- 补充当前生成状态与本地状态忽略规则；
- 在验证文档规定的迁移链时保留旧 compact Snapshot。

Snapshot 升级当前受 calcit-lang/calcit#742 阻塞。Calcit 0.13.77 可以转换旧 direct-quote 源码，但会为 `algebra.test/in-rust:` 生成 Dynamic schema 并要求回退 0.13.51；0.13.50 和 0.13.51 无法读取原始 direct-quote namespace 条目，而 0.13.51 也无法读取 0.13.77 的输出。因此核心迁移路径修复且全部门禁通过前，不应创建目标仓库 PR。

协调 checkpoint：calcit-lang/calcit#731。
